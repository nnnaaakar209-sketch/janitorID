# janitorID

> Enhanced Data Cleaning Tools - A Janitor Modification

## 📊 Overview

**janitorID** adalah package R hasil modifikasi dari `janitor` dengan tambahan fitur:

- ✅ **Konversi Mata Uang Real-time** - 146 mata uang dunia dengan API
- ✅ **Visualisasi Interaktif** - Heatmap, Sunburst, Donut Chart
- ✅ **Auto Data Cleaning** - Pembersihan data otomatis (missing, outlier, duplikat)
- ✅ **Health Dashboard** - Dashboard kesehatan data komprehensif
- ✅ **Statistical Report** - Laporan statistik inferensial otomatis
